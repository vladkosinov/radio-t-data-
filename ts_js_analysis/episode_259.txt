Summary: Extensive technical discussion of Dart language as JavaScript alternative. Hosts analyze Google's Dart language (which compiles to JavaScript), debating whether it's necessary given GWT's capability to translate Java to JavaScript, and JavaScript's universal availability. Discussion covers JavaScript code generation by tools (GWT generates large JavaScript from Java), Node.js as server-side JavaScript platform, and JavaScript's problematic role as a universal compilation target. Focus on whether introducing new languages like Dart makes sense when JavaScript is inevitable.
Key quotes: "Dart в этом смысле намного человечнее, потому что он не пытается сделать вид, что по-честному транслируется в JavaScript прозрачно... какое-то бешеное количество строк занимает скомпилированный Hello World на самом Dart в JavaScript" (Dart is more honest because it doesn't pretend to transparently compile to JavaScript - a huge amount of JavaScript code is generated for simple Dart Hello World); "мне кажется, что ни то, ни другое уже читать не надо, потому что при всем богатстве выбора другой альтернативы нет" (it seems either way you have to use it, because despite all choices, there's no alternative)
