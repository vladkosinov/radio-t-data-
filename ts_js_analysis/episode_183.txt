Summary: Extensive technical discussion of JavaScript security vulnerabilities, particularly in email contexts. Expert Vladimir_Security explains XSS (Cross-Site Scripting) attack vectors involving JavaScript embedded in HTML emails. Discussion covers JavaScript execution in browsers, browser security protections (removing/escaping JavaScript), historical vulnerabilities (Internet Explorer interpreting JavaScript in image tags via javascript: protocol scheme), and the cat-and-mouse game between attackers and security measures. Covers how malicious JavaScript in emails can access cookies and compromise user data.
Key quotes: "Внутри этого HTML есть JavaScript... когда бы ты открыл его в браузере... этот JavaScript в твоем браузере исполнился... имея доступ к твоим куклам" (JavaScript inside HTML, when opened in a browser, executes with access to your cookies); "в части XSS, в части всяких схем, например, схемы JavaScript... иногда бывает, что программисты не успевают затыкать все возможные дырки" (with XSS and JavaScript schemes, programmers sometimes can't plug all the security holes)
