Summary: Technical comparison of JavaScript engine performance across browsers. Hosts discuss Google Chrome's JavaScript speed relative to Safari, Firefox (TraceMonkey), Opera, and Adobe's Flash engine. Extensive benchmarking discussion showing Chrome is slower than Safari and similar to or slower than Firefox. Analysis covers how Chrome wins not through JavaScript speed but through being a minimal, clean browser without extensions. Discussion emphasizes the practical implications of JavaScript performance for real applications.
